Metro Cafe Tycoon - Firebase 설정 안내 (Firestore 직접 저장 · 4자리 PIN 방식)
==========================================================================

1. Firebase Console(https://console.firebase.google.com)에서 프로젝트를 선택합니다.
2. 빌드 > Firestore Database를 생성합니다.
3. 프로젝트 설정 > 일반 > 내 앱에서 웹 앱(</>)을 등록하고 firebaseConfig 값을 복사합니다.
4. `js/firebase-config.js` 파일에 실제 프로젝트 설정값(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)을 붙여넣습니다.
5. `firestore.rules` 규칙을 Firestore 보안 규칙 탭에 반영합니다.
6. 터미널에서 `python build.py`를 실행해 `js/game.js` 번들을 최신화한 뒤 배포합니다.
