Metro Cafe Tycoon — 분리형 프로젝트
===================================

실행
- 폴더 전체를 압축 해제합니다.
- VS Code에서 폴더를 엽니다.
- Live Server로 index.html을 실행합니다. (file:// 직접 실행은 Firebase/ES module 제한으로 권장하지 않습니다.)

파일 구성
- index.html: 게임 화면과 모달 마크업
- css/style.css: 사용자 정의 스타일
- js/src/00_bootstrap_and_data.js: Firebase 초기화, 데이터, 게임 상태
- js/src/01_audio.js: 오리지널 BGM 4곡 재생 엔진 + 라디오 곡 선택 + 날씨 사운드
- js/src/02_customers.js: 손님 생성/이동/주문/퇴장
- js/src/03_simulation_and_hud.js: 시간/날씨/경제 연결/HUD
- js/src/04_shop_and_phone_ui.js: POS, 스마트폰, 홍보 UI
- js/src/04b_market_engine.js: 주식·코인 시장 엔진 (가격 변동, 차트, 뉴스 이벤트, 손익 색상 UI)
- js/src/05_metro_map.js: 수도권 지도와 지점/건물 관리
- js/src/06_accounts_and_cloud.js: 계정, Firebase 저장/불러오기, 랭킹
- js/src/07_effects_and_game_loop.js: 알림, 자동 저장, 메인 루프, onclick 호환
- js/scenery.js: 35개 수도권 상권별 파노라마 풍경 렌더링
- js/furniture.js: 가구 카탈로그 및 아이소메트릭 신규 모델 데이터
- js/firebase-config.js: Firebase Web 앱 설정
- js/economy.js: 경제 기능 모듈
- js/graphics.js: 카페 캔버스 렌더링 모듈
- js/game.js: 실행용으로 생성된 단일 ES 모듈 번들
- assets/audio/: 게임 전용 오리지널 BGM 4곡(MP3, 가사 없는 연주곡)
- tools/make_bgm.py: BGM 4곡을 다시 만들어 내는 작곡/렌더링 스크립트 (python3 tools/make_bgm.py assets/audio)

소스 수정 방법
1. 기능별 js/src 파일을 수정합니다.
2. 프로젝트 최상위 폴더에서 `python build.py`를 실행합니다.
3. 생성된 js/game.js를 포함해 배포합니다.

중요한 호환성 메모
- Firebase 계정 데이터는 Firebase Authentication UID를 기준으로 저장합니다. 기존 PIN 계정은 이전 절차를 거쳐야 합니다.
- 기존 HTML의 onclick 핸들러가 작동하도록 모든 기능 소스를 기존 순서대로 하나의 ES 모듈로 빌드합니다.
- 따라서 기능별 파일은 개발용 원본이며, 직접 index.html에서 각각 script로 불러오면 안 됩니다. 반드시 build.py로 묶어야 합니다.
- Firebase Web 설정은 `js/firebase-config.js`에 넣습니다. Authentication, Cloud Functions, Firestore 보안 규칙 설정은 `FIREBASE_SETUP.txt`를 확인하세요.

검증
- 빌드 결과의 JavaScript 구문 검사를 수행했습니다.
- 실제 Firebase 계정 로그인/클라우드 동기화는 배포 환경에서 별도 확인이 필요합니다.

주식·코인 업데이트 (v2)
- 종목별 최근 10분 가격 차트, 내 평균단가선, 뉴스 발표 시점 표시
- 한국식 색상: 상승/이익 = 빨강, 하락/손실 = 파랑
- 포트폴리오 요약(평가금액·평가손익·수익률·누적 실현손익)
- 뉴스/루머 이벤트: 가격 반영 약 10~20초 전에 알림. 속보는 반드시 반영, 루머는 약 55%만 사실
- 매매 버튼 확장: 주식 1주/10주/전량, 코인 10만원/50만원/절반/전량
- 튜닝 값은 js/src/04b_market_engine.js 상단의 MARKET_CFG 등에서 조정
- 기존 저장 데이터는 그대로 호환됩니다 (새 필드는 자동 보정)


인테리어 가구 & 홀 리뉴얼 업데이트 (v4)
- 하단 과도한 카운터·포스기·소형 머신 그래픽 제거 및 넓은 원목 테이블 홀 구조로 개편
- [매장·가구·메뉴] > [🪑 가구상점·배치] 탭에서 테이블 4종 및 인테리어 소품 4종 구매·슬롯 배치 가능
- 배치한 가구가 카페 실내 화면에 실시간으로 렌더링되며 평판 및 메뉴 판매 단가 보너스 적용
- 손님 입장 → 홀 테이블 착석 → 주문·음용 → 퇴장 동선으로 개편


하단 UI 슬림화 & 홀 테이블·가구 확장 업데이트 (v5)
- 하단 '자동 브루잉 시스템 가동중' 상태바 제거 및 6개 메인 메뉴 버튼을 슬림한 1줄 도크로 개편해 매장 하단 시야 확보
- 홀 테이블 배치를 안쪽 창가 라인(3개 존) + 앞쪽 홀 플로어(3개 존) 총 6개 테이블 존으로 확장 (최대 5명 손님 동시 착석·주문)
- 소품 배치 존 4개(안쪽 좌/우 코너 + 앞쪽 좌/우 포인트) 및 홀 중앙 러그·카펫 3종 커스터마이징 추가
- 가구 상점 신규 가구 7종 추가 (패밀리 오크 4인 롱테이블, 레트로 브라운 가죽 부스석, 우드 글라스 디저트 쇼케이스, 지중해 대형 올리브 나무 화분, 러그 3종)


오리지널 BGM + 라디오 (v7.36)
- 곡 4개: Morning Cafe(아침) / Rainy Day(비) / Sweet Dessert(낮·저녁) / Midnight Jazz(밤) — 모두 가사 없는 연주곡, 끊김 없이 반복됩니다.
- 상단 BGM 버튼 또는 📻 라디오 창에서 곡을 고르거나 ⏮ ⏭ 로 넘길 수 있습니다. 별도 음악 프로그램은 필요 없습니다.
- "자동 추천"을 켜면 비 오는 날/시간대에 맞춰 곡이 부드럽게 바뀝니다. 직접 고르면 그 곡만 반복됩니다.
- 선택한 곡/모드는 브라우저(localStorage)에만 저장되며 게임 저장 데이터 구조는 바뀌지 않았습니다.
- 빗소리(비 오는 날)와 겨울 종소리(눈 오는 날)는 어떤 곡과도 함께 흐릅니다.
- 음원은 Live Server(http)로 실행해야 불러와집니다. 불러오지 못하면 예전 신스 코드음으로 자동 대체됩니다.


대규모 경영·비주얼 업데이트 (v8)
- 매장 캔버스에 쿼터뷰 원근 바닥과 손님·가구 투영을 적용했습니다.
- POS 메뉴·레시피와 즉시 재료 발주를 한 화면에서 관리하고, 메뉴의 부족 재료 표시를 눌러 발주 대상을 선택할 수 있습니다.
- 스마트폰은 문자·카페그램 전용으로 단순화하고, 투자·직원·재료 구독·계절 정산은 가로형 2단 태블릿으로 이동했습니다.
- 전체 창고 용량 대신 재료별 80잔 기본 상한을 사용하며, 계절별 발주 원가와 제철 메뉴 보너스가 적용됩니다.
- 재료 자동 구독, 창고·마케팅·홀 직원, 계절 운영 정산서, 미식 평가단 미션, 단계별 기능 안내 퀘스트를 추가했습니다.
- 자금 부족 경고를 최상단 배너로 표시하고, 문자 이벤트 간격과 주식·코인 가격 변동을 완화했습니다.
- 기존 35개 상권별 파노라마는 `js/scenery.js`에서 계속 사용하며, 신규 아이소메트릭 가구 5종을 추가해 총 215종입니다.
- 소스 변경 후 `python build.py`를 실행해 `js/game.js`를 갱신한 뒤 Live Server로 실행합니다.
- 이메일 입력 없는 사장님 아이디/비밀번호 로그인과 복구 코드 기반 비밀번호 재설정, 기존 PIN 계정 이전을 추가했습니다. Firebase 내부에서는 가상 아이디를 Authentication 계정에 연결하며, 플레이어는 복구 코드를 별도로 보관해야 합니다. 클라우드 기능을 사용하려면 Firebase Web 설정과 Functions/Firestore 규칙 배포가 필요합니다.
- 투자 시장에서 카페토큰 기준가를 18,000원, 시바라떼코인을 12,000원으로 올렸고, 가격 하한도 기준가의 10%로 설정했습니다. 기존 보유량은 단위 전환해 총 투자 원금이 유지되도록 처리합니다.
