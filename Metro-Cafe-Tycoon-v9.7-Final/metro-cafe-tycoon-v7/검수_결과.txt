Metro Cafe Tycoon v7.36 - 오리지널 BGM/라디오 추가 + 코드 점검 결과
======================================

수정/정리
- js/src/*.js 원본 파일을 기준으로 js/game.js 실행 번들을 다시 생성했습니다.
- 원본 소스와 실행 번들의 내용이 일치하도록 정리했습니다.
- 게임 데이터 구조와 기존 저장 데이터 필드는 변경하지 않았습니다.

자동 점검
- JavaScript 파일 구문 검사: 통과
- HTML 중복 ID 검사: 통과
- JS의 정적 DOM ID 참조 검사: 통과 (autoBrewStatusLabel은 선택 요소로 null 검사 적용)
- 검색창 ID 2개(baepangSearchInput, marketSearchInput)는 화면 렌더링 시 동적으로 생성되는 항목으로 확인했습니다.
- autoBrewStatusLabel은 해당 요소가 없어도 오류가 나지 않도록 null 검사하는 코드가 이미 적용되어 있습니다.

배포 전에 꼭 확인할 점
- `js/firebase-config.js`에 Firebase Web 앱 설정용 빈 템플릿이 있습니다.
- Firebase 콘솔의 실제 프로젝트 Web app config를 받아 `js/firebase-config.js`에 입력하세요.
- 설정 후 `python build.py`를 다시 실행하고 재배포해야 합니다.
- Firestore 규칙/계정 보안은 `FIREBASE_SETUP.txt`의 주의사항을 확인하세요.
- 실제 Firebase 연결 및 브라우저에서의 게임 플레이는 이 환경에서 계정/서버 권한으로 검증할 수 없습니다.

실행
- 압축을 푼 폴더를 VS Code로 엽니다.
- Live Server로 index.html을 실행합니다.
- 기능별 코드를 수정했다면 프로젝트 폴더에서 python build.py를 실행한 뒤 배포합니다.


v7.36 추가 점검 (오리지널 BGM / 라디오)
- 4곡 MP3 제작: 약 34~55초 루프, 128kbps, 곡 간 음량 -18 LUFS로 통일, 클리핑 없음
- 헤드리스 브라우저 테스트: 곡 켜기/끄기, 4곡 직접 선택, 이전/다음, 자동 추천, 오류 0건
- MP3 파일을 일부러 막은 상태에서도 게임이 멈추지 않고 기본 신스음으로 대체되는 것 확인
- JavaScript 구문 검사 통과, HTML 중복 ID 없음, 새 DOM ID 참조 모두 존재
- 한계: 실제 스피커로 들어본 청감 확인은 사용자 몫입니다. 마음에 안 드는 곡은 tools/make_bgm.py의 선율/템포를 고쳐 다시 만들 수 있습니다.

Firebase Authentication 전환
- 이메일 입력 없는 사장님 아이디/비밀번호 회원가입·로그인, 복구 코드 기반 비밀번호 재설정, UID별 저장과 공개 읽기 전용 랭킹을 구현했습니다.
- Cloud Functions `reserveCafeIdentity`가 사용자 ID/상호명을 서버에서 중복 확인하고 복구 코드 해시를 비공개로 저장합니다.
- `migrateLegacyCafe`는 기존 PIN 확인, 15분당 최대 5회 제한, UID 저장/랭킹 이전, 기존 PIN/사용자 문서 제거를 처리하며, `recoverCafeAccount`는 복구 코드로 비밀번호를 재설정합니다.
- Firebase Authentication의 Email/Password 제공자는 내부 가상 아이디 인증용으로 필요하지만, 플레이어는 이메일을 제공하지 않습니다. 복구 코드를 잃으면 비밀번호 복구가 불가능할 수 있습니다.
- `firestore.rules`, `firebase.json`, Functions 의존성 및 `FIREBASE_SETUP.txt` 배포 안내를 추가했습니다.
- Firebase Web 설정값과 배포 권한이 없어 실제 로그인·Functions·Firestore 연동 테스트는 미실행 상태입니다.
